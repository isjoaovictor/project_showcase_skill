# Checklist de conclusão

## Verdade do produto

- [ ] Toda afirmação funcional importante é rastreável a código ou documentação.
- [ ] Simulações estão visivelmente rotuladas e não parecem execução em tempo real.
- [ ] Roadmap não é descrito como funcionalidade disponível.
- [ ] Historia e contribuições atribuídas apenas se forem documentadas.
- [ ] Segredos e dados privados não estão publicados.

## Narrativa

- [ ] Origem, proposta, funcionamento, decisões e evolução são compreensíveis.
- [ ] Cada tecnologia responde a uma necessidade concreta do produto.
- [ ] Sem aulas, perguntas de avaliação, quiz, prova, laboratório, exercícios, terminal simulado como centro.
- [ ] Não há «marketing vazio» nem frases genéricas de preenchimento.

## Visual e interação

- [ ] A marca usa os tokens e os assets corretos.
- [ ] Há uma tela forte de entrada e variações editoriais entre capítulos.
- [ ] Cenários e controles funcionam; navegação de ida e volta preserva estado quando relevante.
- [ ] Textos, botões, contraste e focos funcionam com teclado.
- [ ] Telas móveis e `prefers-reduced-motion` funcionam.
- [ ] Sem dependência de serviços pagos ou API keys para rodar a demonstração.
